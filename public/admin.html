Discovery inbox — new openings

Scans Canada-wide local media for newly-opened attractions, drafts catalog entries with Grok, then runs the autopilot verification chain: a Google Places closed-tag veto (only an explicit "closed" listing blocks) + the Grok editorial gate. Finds that pass publish to the live catalog automatically (✓); the rest wait here — verify facts yourself, then Copy catalog entry → data/curatedCatalog.js.
